# Security Policy

This repository's threat model, trusted boundaries and deployment guidance live in
[docs/SECURITY.md](docs/SECURITY.md). Read it before exposing either the DSH plugin or the
`browser-pods` MCP endpoint beyond loopback.

If you believe you have found a vulnerability, please **do not open a public issue**. Contact the
maintainer privately (open a GitHub security advisory on this repository, or email the address in
the repository profile) with:

- affected component (plugin or `mcp/`), version/commit,
- a minimal reproduction (URLs, tool calls, configuration),
- the impact you believe it has.

Please allow a reasonable disclosure window before publishing details.
